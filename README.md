# График смен — PWA

Это версия HTML-приложения, подготовленная для установки на телефон как PWA.

## Что загружать на GitHub

Загрузи содержимое этой папки в корень репозитория:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- папку `icons/`

## GitHub Pages

1. Создай репозиторий на GitHub.
2. Загрузить в него все файлы из этой папки.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`.
6. Сохрани и дождись публикации сайта.

После публикации открой ссылку GitHub Pages на телефоне.

### Android
В Chrome открой сайт → `⋮` → **Установить приложение** / **Добавить на главный экран**.

### iPhone
Открой сайт в Safari → **Поделиться** → **На экран «Домой»**.

После установки приложение открывается отдельно, без обычной адресной строки браузера.
